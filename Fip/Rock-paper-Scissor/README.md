# Rock Paper Scissors

## Description

A simple Python Rock Paper Scissors game where the user plays against the computer.

## Features

- Allows the user to choose rock, paper, or scissors
- Generates a random choice for the computer
- Determines whether the user wins, loses, or ties
- Validates the user's input

## Requirements

- Python 3.x

## How to Run

Run the following command in a terminal:

```bash
python rock_paper_scissor.py
